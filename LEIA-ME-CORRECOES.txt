2. TELEFONES (dos entregadores / "da rua") AGORA FUNCIONAM:
   - Antes: a API devolvia os telefones mas na tela do pedido eles NÃO
     apareciam, e onde apareciam era só texto com um emoji 📞 (não dava para
     tocar para ligar).
   - Agora: no detalhe de cada pedido aparecem o telefone do cliente e do
     entregador com DOIS botões tocáveis:
       [📞 Ligar]  → abre o discador do celular (link tel:)
       [💬 Zap]    → abre o WhatsApp direto (wa.me, com código +55)
   - Os telefones também são clicáveis nos painéis do Admin: lista de
     usuários, Financeiro (lojas/entregadores), Antecipações e Suporte (esperando).
   - Números brasileiros (10/11 dígitos com DDD) recebem automaticamente o
     código de país +55 para WhatsApp e ligação funcionarem.

=== COMO EXECUTAR ===

Opção A (mais fácil, nesta máquina):
  ./iniciar.sh
  → abra http://localhost:3000

Opção B (passo a passo):
  1. Instale o PostgreSQL e crie: usuário pediu / senha pediu123 / banco pediuchegou
  2. npm install
  3. npm start
  → http://localhost:3000

Opção C (Docker, se tiver Docker):
  docker compose up --build

  - Comente SEED_DEMO=1 e descomente NODE_ENV=production

    e coloque PGSSL=1 se o provedor exigir SSL.
  - A câmera (reconhecimento facial) só funciona em HTTPS ou localhost.
